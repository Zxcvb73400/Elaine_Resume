解決問題

我處理的多半是「資料都在系統裡，但用起來很費工」的問題：部門靠共用 Excel 手動整理報表、申報要一筆一筆登入政府網站、採購要逐個網站查價。

在全一電子，我把各部門原本共用的 Excel 改成報表：每個人每次的操作都有紀錄，常用的統計做成模板圖表，不必每次重新拉資料，共完成 20 多張。接案時，則把會計業者的營所稅申報和核定通知書查詢改成自動流程。

常用技術 PythonSQLMSSQLOracleFineReportPower AutomateUiPathFastAPIPostgreSQLHTML／CSS／JavaScriptGit
也做過 教育 AI 平台前端與 QA AI／RPA 導入評估 網頁前後端（Laravel） 遊戲圖鑑網站 Unity／網頁遊戲開發 Python 自動鋼琴

怎麼做事

動手前，我會先弄清楚三件事：結果要不要完全正確、導入要花多少成本、之後由誰維護，再決定用什麼工具。

資料庫裡的資料要定期更新，就用 SQL 排程；固定的統計表要定期寄給負責人，就用 FineReport 定時任務；政府網站沒有 API、結果又必須正確，就用 RPA 模擬操作；需要理解大量文字、可以接受人工複核的工作，才評估 AI。

以營所稅申報為例：先訪談會計人員，記下原本每件申報要做哪些步驟、花多久；確認政府網站沒有 API 可以接之後，選用 Power Automate 模擬網站操作，用 Excel 整理資料；過程中處理大量件數跑到一半記憶體不足的問題，最後交給會計人員核對再送件。5 月共處理約 300–500 件。

全一電子 · 數位整合部

跨部門報表電子化與自動化

FineReportMSSQLOracleSQL 排程RPA

要解決的問題

人資、採購、供應鏈、職安、品保等部門原本大多開共用 Excel 整理資料：誰改了什麼難以追蹤，每次要看統計都得重新拉一次。資料則分散在 ERP、BPM、內部網站等系統的資料庫中。

我的做法

  • 以人資、採購等需求最急的部門優先，再擴展到品保等其他部門。
  • 把共用 Excel 改成報表：每個人每次的操作都留有紀錄；常用的統計依需求做成模板圖表，不必每次重新拉資料。
  • 從 ERP、BPM、內部網站等系統擷取 MSSQL、Oracle 資料，獨立開發及維護報表，涵蓋庫存分析、物流追蹤、職務說明書等。
  • 依資料更新頻率、作業流程及執行方式，選擇 SQL 排程、FineReport 定時任務或 RPA，完成資料更新、報表產出，並每日／每月自動寄送統計總表 Email。
  • 負責資訊部門同仁的 FineReport 教育訓練，讓團隊也能接手維護。

成果

20 多張報表上線並持續維護。負責專案相關績效金額約佔部門年度 KPI 金額三分之二，個人累積貢獻逾新台幣百萬元。

自由接案 · 會計業者

營所稅申報流程自動化

Power AutomateRPAExcel

要解決的問題

營利事業所得稅申報需要反覆登入政府網站、查看畫面資料、整理到 Excel 再送件，重複性高。

主要限制

政府系統不支援常見的 API 介接方式，只能直接在畫面上操作。

技術選擇與做法

  • 透過客戶訪談了解原有人工流程及單件作業時間。
  • 規則固定、結果必須正確，又沒有 API 可用，因此選用 Power Automate（RPA）模擬網站操作。
  • 搭配 Excel 整理資料，並完成申報送件；會計人員仍會自行核對結果。
  • 處理執行時的記憶體不足與各種錯誤情境，讓大量件數能穩定跑完。

成果

於 5 月處理約 300–500 件申報。相較原人工流程，單件重複作業時間減少約 80%（依客戶訪談）。

要解決的問題

個人專案 · AI 協作

遊戲圖鑑網站

資料清洗交叉核對資料關聯設計網頁開發SEO
查看網站 ↗

要解決的問題

遊戲資料散落在小紅書圖片、網路資料與官方資訊中，內容多為簡體中文，玩家查找與比對不便。

  • 由 AI 生成初步前端，再依我的需求調整，最後自己修細節；玩家紀錄儲存在本機，可用 JSON 匯入匯出，並套用 SEO 概念。

成果

已通過使用者測試，回饋可有效縮短資料查找時間；預計公開供玩家免費使用。
