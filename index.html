全一電子 · 與資訊部門同事協作開發

跨部門報表電子化與自動化

UiPath（RPA）UiBot（RPA）SQL 排程OracleMSSQLFineReport

要解決的問題

人資、供應鏈、職安、品保等部門原本大多開共用 Excel 或是紙本整理資料﹑跑簽核：誰改了什麼難以追蹤，每次要看統計都得重新拉一次。資料則分散在 ERP、BPM、內部網站等系統的資料庫中。

最常遇到的問題

資料與需求要靠人推動：時常需要打電話催資料、反覆詢問需求、開會確認，同時還要克服各系統的限制，盡量做出符合使用者需求的報表。

我的做法

  • 根據部門提出先後及重要程度，依次進行訪談及製作。
  • 與建置 ERP／BPM 系統的同事合作，撈取其系統資料串成報表。
  • 把共用 Excel 改成報表：每個人每次的操作都留有紀錄；常用的統計依需求做成模板圖表，不必每次重新拉資料。
  • 依資料更新頻率、作業流程及執行方式，選擇 SQL 排程、FineReport 定時任務或 RPA，完成資料更新、報表產出，並每日／每月自動寄送統計總表 Email。
  • 負責資訊部門同仁的 FineReport 教育訓練，讓團隊也能接手維護。

代表作：職務說明書

原本是紙本，由我全權負責電子化，製作期程最長。需要依組織設計階層，並依使用者權限隱藏內容，但原系統做不到；我上論壇發問、反覆嘗試，最後利用既有欄位判斷權限，做到依權限顯示。

成果

20 多張報表上線並持續維護，各部門每日／每月固定使用，並持續回饋報表疑問、檢查與測試。負責專案相關績效金額約佔部門年度 KPI 金額三分之二，個人累積貢獻逾新台幣百萬元。

自由接案 · 與非資訊背景會計業人員合作開發

營所稅申報自動化

Power Automate（RPA）Excel

要解決的問題

會計事務所每年 5 月要處理 300–500 家客戶的營所稅申報，依客戶資料反覆登入政府系統、逐筆操作與整理，重複性過高。

主要限制

政府系統不支援常見的 API 介接方式，只能直接在畫面上操作。
客戶完全不熟資訊系統，也不想另外安裝程式或執行環境；連測試時該按哪裡、自動化執行時不要操作電腦，都需要事先說明並耐心回覆。

我的做法

  • 訪談會計人員，依對方說明的步驟整理流程。
  • 規則固定、結果必須正確，又沒有 API 可用，加上客戶不想另外安裝環境，依實際狀況來回調整後，選用 Power Automate（RPA）模擬網站操作。
  • 自動送件至政府系統，執行到一半自動清理快取，讓大量件數能穩定跑完。
  • 下載系統回傳資料並整理至對應客戶資料夾，自行設計 Excel 讓使用者檢查申報成功／失敗，並記錄 20 多種失敗原因，最常見的是稅籍編號錯誤與欄位未填寫。

成果

於 5 月處理約 300–500 件申報，單件重複作業時間減少約 80%。客戶持續合作，至今共完成三個案子。

個人專案 · AI 協作

遊戲圖鑑網站

資料清洗交叉核對資料關聯設計網頁開發

要解決的問題

遊戲資料散落在小紅書與外部網站，形式有文字、Excel、圖片，內容多為簡體中文或其他語系，玩家查找與比對不便。

我的做法

  • 讓 AI 讀取攻略圖片撈出資料（正確率約 80%，僅數字較為正確），我再自行翻譯、開遊戲比對整理，最後用 Excel 欄位交叉比對，初步整理並核對約 500 筆資料。
  • 依比對結果讓 AI 設定欄位規則；自行設計資料關聯與成本表，列出原料售價／購買價，計算「售價－原料成本」，並加上活動時間判斷。
  • 由 AI 生成初步前端，再依我的需求調整，最後自己修細節；玩家紀錄儲存在本機，可用 JSON 匯入匯出。
  • 依測試玩家回饋新增欄位與排序，並修正 bug。

成果

已通過小部分使用者測試，回饋可有效縮短資料查找時間；尚未正式上線，預計 11 月中供玩家免費使用。
